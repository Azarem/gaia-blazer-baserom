# I009 open questions (PA batch A5, library `0118`)

IDs are scoped to this iteration. Nothing here is written into names, notes, comments, `blocks.json`, `overrides.json` or the docs as fact. Mode: R = static read only, R+S = read, then confirm with a short Mesen2 run, S = needs a runtime run, D = needs a decision. Tag DISCREPANCY marks a mismatch between the ROM text or code and a document (the walkthrough or `docs/`). Tool column names the `user-mesen2-mcp-dev` tools. Addresses are `$bank:address` (LoROM; A5 code is in bank `$02`, so `code_0118FC` is at `$02:98FC`; a label suffix `xxYYYY` is the file offset in hex, so the address is `$(off >> 15):(8000 + (off & 7FFF))`). Section numbers and `L###`/`D##` row ids refer to `plans/doc-audit/function-map/FM-A5.md`.

The walkthrough was checked for every claim that names an item, a stat, a button or a screen. All 64 item names and the weapon, armor and magic descriptions agree except the rows tagged DISCREPANCY (1, 3, 6). The ROM text is the reference for spelling; the strings print the period glyph as `-` in the extract.
