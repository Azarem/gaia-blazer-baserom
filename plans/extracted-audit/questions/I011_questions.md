IDs are scoped to this iteration. Nothing here is written into names, notes, comments, `blocks.json`, `overrides.json` or the docs as fact. Mode: R = static read only, R+S = read, then confirm with a short Mesen2 run, S = needs a runtime run, D = needs a decision. Tag DISCREPANCY marks a mismatch between the ROM text or code and a document (the walkthrough or `docs/`). Tool column names the `user-mesen2-mcp-dev` tools. Addresses are `$bank:address` (LoROM; a label suffix `xxYYYY` is the file offset in hex, so the address is `$(off >> 15):(8000 + (off & 7FFF))`; `code_0133A6` is at `$02:B3A6`, `asset_list_028000` at `$05:8000`). Row ids (`L0nn`, `Dnn`) and section numbers refer to `plans/doc-audit/function-map/FM-A7.md`.

The walkthrough was checked for every claim that names a place, a boss or a screen: ROM place names agree with the walkthrough and the crosswalk (capitalisation aside). The intro and ending story text, "Freil Empire" and the dream-room scene ids are not in the walkthrough, so there is nothing to compare them with; no row is tagged DISCREPANCY.
