# I010 open questions (PA batch A6, library `0124`-`0127`: text renderer, dialogue renderer, name entry, staff roll, menu graphics loaders)

IDs are scoped to this iteration. Nothing here is written into names, notes, comments, `blocks.json`, `overrides.json` or the docs as fact. Mode: R = static read only, R+S = read, then confirm with a short Mesen2 run, S = needs a runtime run, D = needs a decision. Tag DISCREPANCY marks a mismatch between the ROM text or code and a document (the walkthrough or `docs/`). Tool column names the `user-mesen2-mcp-dev` tools. Addresses are `$bank:address` (LoROM; A6 code is in bank `$02`, so `code_012769` is at `$02:A769`; a label suffix `xxYYYY` is the file offset in hex, so the address is `$(off >> 15):(8000 + (off & 7FFF))`). Row ids (`GX`, `NE`, `ST`, `TR`, `DL`, `HL`, `SD`) and section numbers refer to `plans/doc-audit/function-map/FM-A6.md`.

The walkthrough was checked for every claim that names a screen, a character, a stat or a boss: the name entry (`01-in-the-beginning.md`), the HP bar colours and the fifty units (`level-up.md`), the credits (`08-world-of-evil.md`) and Deathtoll's HP (`enemy-bestiary.md`). The only mismatch is OQ-I010-2. The credits text and the in-game Deathtoll spelling are not quoted by the walkthrough in a form that can be compared beyond that.
