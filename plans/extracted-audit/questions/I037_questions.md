IDs are scoped to this iteration and cover only new findings. `OQ-I033-1` (ROM HP of Poseidon is 79, the bestiary says 70) and `OQ-I033-3` (the stats of the snowball type `$31` and the Ice Crystal type `$35`, the EXP `$4000` against the bestiary's 0) stay valid and are cited by ID where a note relies on them. `OQ-I005-14` (the unexplained `$16` bits) is related to OQ-I037-5.

Depth: actors, light. Names from the walkthrough (`docs/walkthrough/05-mountain-of-souls.md`, `enemy-bestiary.md`), a block note per file, a part note per actor root, comments only for non-obvious logic. Many monster movements are animation data, not script, so the static notes describe the script and name that as a limit.

Mode: R = static read only, R+S = read, then confirm with a short Mesen2 run, S = needs a runtime run, D = needs a decision.
