# I013 open questions (PA batch A9, library `0270`-`0279`: save and load, scene change and transitions, map index helpers, pause, EXP and Gems, fixed state init)

IDs are scoped to this iteration. Nothing here is written into names, notes, comments, `blocks.json`, `overrides.json` or the docs as fact. Mode: R = static read only, R+S = read, then confirm with a short Mesen2 run, S = needs a runtime run, D = needs a decision. Tag DISCREPANCY marks a mismatch between the ROM code and a document (the walkthrough, `docs/` or an earlier function map). Tool column names the `user-mesen2-mcp-dev` tools. Addresses are `$bank:address` (LoROM; a label suffix `xxYYYY` is the file offset in hex, so the address is `$(off >> 15):(8000 + (off & 7FFF))`; `code_0270E4` is at `$04:70E4`, `code_0279B5` at `$04:79B5`). Row ids (`L0nn`, `Dnn`) and section numbers refer to `plans/doc-audit/function-map/FM-A9.md`.

The walkthrough was checked for every claim that names a place, a stat or a screen: the EXP cap (99,999,999, a four-byte stat at `0x7E1B78`), the monster-lair count shown by Start and the location banner agree with the code. The walkthrough gives no Gems cap (OQ-I013-8). Two rows are DISCREPANCY rows against project documents (OQ-I013-1 and OQ-I013-2); none is against the walkthrough.
