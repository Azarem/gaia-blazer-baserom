## Findings and corrections

- **Dispatch convention written down once** (`cop_core` block note): `HandleCop` sets X = Y = slot, dp$38 = operand pointer, dp$3A = script bank; a handler starts with `TYX` and leaves through the exit chain (`CopExitSkip5`-`Skip1`, `Continue`, `Jump`, `SaveResume`, `Yield`); A and Y are scratch.
- **Corrections to FM-A3 and the old `docs/cop/index.md`:** `CopAD` waits while the actor is OFF screen; `Cop91` has 414 uses (not 0); `Cop26` is the spell price check (Gem cost, free with the Magic Bell, halved with the Magic Armor, from `docs/walkthrough/items.md`); `Cop25`, `Cop36`, `Cop02` are unused (Gem pickups and EXP use `lib_player_stats` and `Cop38`); `Cop2A`/`Cop2B` offsets are relative; `Cop30` compares a lair record index; the RNG state is `$0302`-`$0311`; `Cop05` rewinds by 2 to the COP instruction, not over the operand.
- **Wait timing:** the script runs when `$14` goes below 0, so `Cop1B` with delay N runs N + 1 frames later; two commands `Cop03 #N` and `Cop04` with nothing between are a pause.
- **Music change** is a handshake of the spawned actor with the SPC (`$F1` fade, wait, `$F0` stop, wait, `$FF` boot, IPL upload with NMI off, `$01` finish); command meanings from `docs/audio/spc-disassembly.md`, directions marked inferred (OQ-I025-2). `table_00FB49` holds 21 track pointers; scripts use six.
- **Tile model:** `tile_type_map` low nibble = type, `$F0` = block mark; the actor's y is its bottom edge, so the row it stands on is y - 16. `Cop21`-`24`/`28` test the whole byte, `CopAE` the low nibble.
- **Spawn model:** the spawn handlers never check the carry of `PopFreeSlot`; with a full pool they write into scratch slot `$06AA`.
- **Walkthrough check:** Magic Bell, Magic Armor and the name entry of In the Beginning were compared with the chapter files; no DISCREPANCY.
- **No ad-hoc scripts:** a one-off Node command for the docs edits was started and failed on a quoting error; the docs were then edited with the editor tool.
