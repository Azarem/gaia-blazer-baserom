## Findings and corrections

- **FM-A8 correction (code against the function map).** Row C09 says `COP [10]` in `code_007650` 'spawns actor `$0D00`'. `COP [10]` is `Cop10_SetNextScene`: area `$00`, scene `$0D` (operand word `$0D00`, area in the low byte), arrival animation 2, x = y = 0. Before it, `code_007647` runs `COP [31] ( #00 )` (music fade, track 0) between two `$F0`-frame waits. The `StaffRollText` part note describes this chain; the notes follow the code. The `lib_0126CF` block note (batch A6) omits the `COP [31]` step; it was left alone (not this batch) and is reported here.
- **A wrong sentence of another batch, fixed.** The `Cop1A_ChoiceMenu` note said `014F43` was a Yes / No question; it is the Record / Quit window of the Master's menu. The two Cop1A notes now name the five strings by their labels.
- **Choice window geometry is regular.** For all five strings `w` of `[07:w,h]` equals the widest option line including its leading blank, `h` is two rows per option, every window starts in column 4 and ends on tile row 15, and the trailing `[CUR:c]` is the arrow cell of the first option (origin + `$82`). The count in the `COP [1A]` operand has to equal the number of lines (nothing checks it). This is in the block note of `shared_choice_prompt_texts`.
- **The chooser.** Option spacing is `$80`; the selected index lives at `$01,S`; Up on the first and Down on the last option are ignored (they fall back to the drain loop); B confirms with carry clear (`BRK #$18`), Y cancels with carry set (`BRK #$07`); the arrow stays drawn on the final option. `BlinkChoiceCursor` is shared with `ChooseMenuRow` / `ChooseMenuRowAtTable` (6 call sites in all); its period is 32 frames (24 on, 8 off).
- **The Master's menu.** The walkthrough's 'northern square ... save your adventure, as well as move on later in the game' is `common_actor_00766C`: Record saves (`lib_save_system.code_0270E4`), Move sets `scene_next = 9` and a per-world warp position. The menu offers Move only when flag `$1B00` is set, which `code_01A0C6` of `gv_village_actors_019475` does right after the Master's Brown Stone speech (`COP [09] ( #$9B00 )`). Where Move leads is `OQ-I030-1`.
- **Return prompts.** `ChoiceStayGoBackText` is asked by six scripts, one per world; the cancel pointer of each is the Stay branch. The warps go to areas `$01`, `$04`, `$06`, `$0A`, `$0D`, `$10`. The wording differences ('Seabed Palace', 'location of the Mountain of Souls') are `OQ-I017-1` and `-2`; no new DISCREPANCY arose.
- **Item names.** The 65 strings agree with `items.md` and the crosswalk; the ROM spellings that differ (the four possessive names without apostrophe, 'Emblem A' to 'Emblem H', id `$26` 'Leaves' like id `$1E`) are the existing `OQ-I004-6` / `OQ-I027-3`. Labels are id-based (`ItemName0A`), strings keep the ROM text; only ids 0 and `$26` got part notes of their own.
- **Chest and lair messages.** The four siblings of `ChestGemsFoundText` all end with `[JMP:&ChestGemsFoundText+M]`, so the key wait and the box erase exist once. `text_arg` is the only parameter (NPC name index, item id, or Gem amount as 3 BCD digits). 'recieved' and 'GEMs' are kept as printed (the walkthrough writes 'Gems').
- **Staff roll.** 218 line breaks x 32 frames = 6976 frames (static estimate, `OQ-I030-2`); the credits text has `Soul Blader` and `COPORATION` (twice) as printed; the glyph runs are font tiles (`OQ-I010-11`). The walkthrough only says 'Enjoy the credits'.
- **Mnemonics:** none added (no new evidence for an unnamed RAM cell; `menu_count`, `menu_blink`, `text_arg`, `choice_result`, `text_last_window_origin` and `vram_upload_flags` already exist).
- **Scope decisions.** `unk14_017504` (D10) stays one part (`MapPatchRectsAndMapSizes`): `blocks` has no split operation (`OQ-I030-3`). The 65 item name strings got no part notes of their own beyond ids 0 and `$26`: the list note covers them, as `NpcNameStrings` does for its strings.
- **Hex to decimal.** The decimal offsets of the names spec came from the FM-A8 tables (checked by the tool against the extracted labels); there was no ad-hoc script for names, notes, comments or docs. The only hand edit outside the tools is the one-token change in `docs/wram-memory-map.md`.
